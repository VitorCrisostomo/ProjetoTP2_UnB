Sistema de Ocorrências
======================

Documentação técnica do backend do projeto de
Técnicas de Programação 2 da Universidade de Brasília.

O ambiente de desenvolvimento utiliza Python 3.14, Flask e SQLite, além de
pytest, pytest-cov, Ruff, mypy e Sphinx.

Esta versão prepara as ferramentas e contém um módulo de exemplo. A aplicação
Flask e as funcionalidades do sistema de ocorrências ainda serão implementadas.
