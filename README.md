# ProjetoTP2 UnB

Sistema de registro e acompanhamento de ocorrências para Técnicas de
Programação 2 da Universidade de Brasília.

## Desenvolvimento do backend

Consulte o [guia de desenvolvimento do backend](backend/README.md) para instalar
Python 3.14, criar o ambiente virtual, baixar as dependências e executar testes,
cobertura, análise estática e documentação.

O checkout atual contém a preparação das ferramentas e exemplos de código.
A aplicação Flask e as funcionalidades descritas nas historietas ainda serão
implementadas; não há comando de inicialização da API nesta versão.

## Desenvolvimento do frontend

Consulte o [guia de desenvolvimento do frontend](frontend/README.md) para instalar
Node.js e as dependências, iniciar o Next.js e executar testes, cobertura,
formatação, análise estática, verificação de tipos e documentação TypeDoc.

O frontend inclui uma página inicial executável para validar o ambiente.
As funcionalidades das historietas e a integração com o backend serão implementadas.

Repositório oficial: [VitorCrisostomo/ProjetoTP2_UnB](https://github.com/VitorCrisostomo/ProjetoTP2_UnB).
